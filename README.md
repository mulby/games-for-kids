# Games for Kids

Story-driven learning games that run in a browser (built for an iPad).

## Math
- [`math/moonlit-map/`](math/moonlit-map/) — **The Moonlit Map**: a gentle, adaptive skills check across six lands
  (number sense, place value, addition, subtraction, multiplication, fractions/time/money), from kindergarten to 3rd grade.
  Press and hold "Grown-ups" on the map for a summary of where she stands.

Each game is a single self-contained `index.html`. Open it in a browser to play.
When it runs as a Claude artifact, results also save to the artifact's database; elsewhere they stay on the device.
